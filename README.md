# Расписание — PWA для студентов

## О проекте
«Расписание» — прогрессивное веб-приложение (PWA) для просмотра и редактирования
личного расписания занятий. Решает проблему: студент тратит время на поиск
актуального расписания в разных источниках и не может быстро добавить изменение.
Целевая аудитория — студенты вузов и колледжей.

## Функциональность MVP
- Просмотр расписания на сегодня
- Создание новой пары (дисциплина, время, аудитория, заметка)
- Редактирование и удаление пары
- Сохранение данных локально (IndexedDB) — данные не теряются при перезагрузке
- Офлайн-режим (Service Worker)
- Валидация форм: пустые поля, корректность диапазона времени, пересечение пар
- Адаптивная вёрстка для смартфонов и десктопа

## Требования к окружению
- ОС: Windows 10/11, macOS, Linux
- Браузер: Chrome 120+, Firefox 120+, Edge 120+
- Node.js 18+ (только для запуска линтера и http-server)
- Сеть — только для первого запуска (далее офлайн)

## Установка и запуск
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/nullpointerhero-bit/timetable-for-students.git
   cd timetable-for-students
   ```
2. Установить зависимости (для линтера и локального сервера):
   ```npm install
   npx http-server . -p 8080
   ```
3. Открыть в браузере: http://localhost:8080. Проверить работоспособность: открыть экран «Сегодня», добавить пару,
    перезагрузить страницу — пара должна сохраниться.
Переменные окружения для MVP не требуются; файл .env.example приложен
для совместимости с шаблоном команды.

## Тестирование
```bash
npm run lint      # ESLint — статический анализ
npm test          # чек-лист TC-01…TC-08 (ручное выполнение по tests/checklist.md)
```
Ограничение: автоматизированных unit-тестов нет; тестирование функциональное
(ручное) и интеграционное (UI + IndexedDB).
