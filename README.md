# Расписание — PWA для студентов

## О проекте
«Расписание» — прогрессивное веб-приложение (PWA) для просмотра и редактирования
личного расписания занятий. Решает проблему: студент тратит время на поиск
актуального расписания в разных источниках и не может быстро добавить изменение.
Целевая аудитория — студенты вузов и колледжей.

## Функциональность MVP
- Просмотр расписания на сегодня
- Создание новой пары (дисциплина, время, аудитория, заметка)
- Редактирование и удаление пары
- Сохранение данных локально (IndexedDB) — данные не теряются при перезагрузке
- Офлайн-режим (Service Worker)
- Валидация форм: пустые поля, корректность диапазона времени, пересечение пар
- Адаптивная вёрстка для смартфонов и десктопа
