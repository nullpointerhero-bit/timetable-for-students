# Пользовательское руководство

**Проект:** «Расписание» — прогрессивное веб-приложение (PWA) для просмотра и редактирования личного расписания занятий.

Руководство предназначено для основной категории пользователей — студентов. Для работы с приложением не требуется знание технологий разработки.

> **Примечание:** регистрация и вход в систему не предусмотрены. Данные хранятся локально на устройстве пользователя (IndexedDB), поэтому учётная запись не требуется.

---

## 1. Начало работы

1. Открыть приложение по адресу `http://localhost:8080` (или опубликованной ссылке).
2. Дождаться загрузки экрана «Сегодня».
3. При первом запуске список пуст — данные хранятся локально, регистрация и вход не требуются.

**Ожидаемый результат:** пользователь получает доступ к функциям продукта.

---

## 2. Основной сценарий: добавление пары

1. Нажать кнопку «+ Добавить».
2. Заполнить поле «Дисциплина» (например, «Математика»).
3. Указать «Время начала» (09:00) и «Время окончания» (10:30).
4. Указать «Аудитория» (101), при необходимости — «Заметка».
5. Нажать «Сохранить».
6. Убедиться, что пара появилась в списке на сегодня.

**Ожидаемый результат:** пользователь достигает своей цели — пара добавлена в расписание и сохранена в IndexedDB.

---

## 3. Изменение или удаление данных

### Редактирование пары

1. Нажать на пару в списке.
2. Изменить нужные поля (например, аудиторию на 102).
3. Нажать «Сохранить».

### Удаление пары

1. Нажать кнопку «Удалить» напротив пары.
2. Подтвердить удаление в диалоговом окне.

**Ожидаемый результат:** данные обновлены или удалены с подтверждением; изменения сохранены в IndexedDB.

---

## 4. Решение типичной проблемы

**Сообщение об ошибке:** «Время окончания должно быть позже времени начала» (или «Пара пересекается с существующей в этой аудитории»).

**Действия пользователя:**

1. Проверить поля «Время начала» и «Время окончания» — окончание должно быть позже начала (например, 09:00–10:30, а не 12:00–11:00).
2. При пересечении пар изменить время или аудиторию.
3. Повторно нажать «Сохранить».

**Ожидаемый результат:** пользователь восстанавливает работу и успешно сохраняет пару.
